- [x] 1.3 实现 `EVIDENCE_MISSING`：仅在标题、正文和投票均为空，且没有媒体、任一图片缺少可用 OCR 文本或任一视频缺少可用当前媒体证据时产生；按实际媒体集合处理图片、视频和混合媒体，不采用二选一假设。
- [x] 1.4 确认 `PolicyRule` 的动作、阈值和自动执行许可继续是内容语义的唯一自动处置授权来源。

## 2. 自动处置资格与历史边界

- [x] 2.1 为 `RiskEvidence` 增加仅含本地记录标识、证据类型、规范化文本指纹和视频时间位置的媒体来源引用字段，并生成迁移；不得保存媒体 URL、二进制或上游认证数据。
- [x] 2.2 在空文字输入时，将当前决定风险依据回链到成功图片 OCR 或当前视频证据；写前重新验证来源记录、文本指纹和视频时间位置。回链失败只拒绝自动处置并记录脱敏审计，不得新增 `EVIDENCE_MISSING` 或改写既有重点原因。
- [x] 2.3 调整自动资格检查：仅 `EVIDENCE_MISSING` 可作为重点原因否决自动处置；保留决定规则、决定依据、置信度、授权开关、配额、幂等、原创/正常状态和写前复核。
- [x] 2.4 以当前可用视频证据而非 `status == SUCCEEDED` 判定视频证据充分；允许 `PARTIAL` 当前提取的完整帧 OCR、二维码或语音转写作为决定依据来源，并在写前校验记录归属、指纹与时间位置。
- [x] 2.5 确保发布不会自动修改、清除或重新入队历史含旧重点原因的任务；显式重评可按新评估改写当前任务。即使当前任务仍含旧重点原因且已有待执行自动任务，写前也必须拒绝、不得调用上游写入并保持人工待审核。
- [x] 2.6 为 `VideoExtraction` 增加提取时 `VIDEO_MAX_DURATION_SECONDS` 上限快照字段并生成迁移；创建提取记录时写入该快照，超过快照时仍保存 `duration_ms`，再写入 `SKIPPED_LIMIT + video_duration_limit_exceeded`。

## 3. 最小验证与文档

- [x] 3.1 增加正向测试：高额奖励与明确私服或引流证据同时存在、决定规则已授权且置信度达标时，会创建 `AI_AUTOMATED_MODERATION` 任务。
- [x] 3.2 增加正文为空的正向测试：决定依据可回链到当前图片 OCR 或视频时间证据，且媒体证据充分时，可创建自动处置任务。
- [x] 3.3 增加负向测试：仅有高额奖励而无明确风险上下文时，不得建议私服/引流或创建自动处置任务；无文字来源且缺少媒体、图片 OCR 或视频证据时必须保留 `EVIDENCE_MISSING`；媒体证据充分但来源回链失败时必须拒绝自动处置、保留原重点状态并写入脱敏审计。
- [x] 3.4 回归测试：图文视频混合、静音视频、`PARTIAL` 但有可用视频证据、非正常帖子状态和任一自动授权关闭时，符合规则的任务不被误拦截或越权自动处置。
