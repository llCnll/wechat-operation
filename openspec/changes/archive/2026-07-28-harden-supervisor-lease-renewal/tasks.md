- [x] 2.1 调整 `Supervisor.run_forever()`：续租失败时记录可观测错误、跳过当轮调和并在下一周期重试，不进入全局关闭路径。
- [x] 2.2 在续租恢复后记录恢复事件，并仅在成功续租后的周期恢复既有服务调和；保持 bootstrap 首次租约写入失败即启动失败的语义。
- [x] 2.3 对连续续租失败日志实现首条立即记录、每 60 秒限频汇总和恢复累计次数，并增加自动验证。

## 3. 自动验证

- [x] 3.1 增加原子发布测试：分别模拟 Windows `winerror=5` 与 `winerror=32` 后重试成功，确认目标内容完整且无遗留临时文件；持续失败时抛出原始错误并清理临时文件。
