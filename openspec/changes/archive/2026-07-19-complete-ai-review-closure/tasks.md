## 2. OCR 与 AI 后台任务链

- [x] 2.1 实现图片 OCR worker 处理器：遍历可访问图片媒体、调用已配置 OCR 适配器、保存媒体关联的文本/置信度/脱敏错误摘要。
- [x] 2.2 实现 AI 评估 worker 依赖检查：等待相关 OCR 作业完成或确定无需 OCR，合并可用 OCR 文本后调用 Schema 校验的 AI 适配器。

- [x] 2.5 将 OCR 与 AI 处理器注册到 `run_worker`，并在原创帖首次入库和内容刷新后触发入队。
- [x] 2.6 提供受控的管理命令或后台入口，为已有原创帖补建流水线任务，并确保相同输入不会重复消耗模型调用。
