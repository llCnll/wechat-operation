# 回复 FAQ 资料维护

仓库中的 FAQ 工作簿和 JSON 是跨游戏通用示例，不代表任何部署方的实际客服政策。工作簿仅用于人工审阅；服务运行时不直接读取 Excel。

运行时只读取 `reviews/data/community-reply-faq.v1.json`。每条规则保留稳定 ID、场景、关键词、回复要点、待补充信息、示例来源说明和禁止承诺；变更后更新资料版本。部署方在启用前应审核渠道、适用条件和可作出的承诺，再对安全样本进行人工检查。

FAQ 命中的安全帖子提供亲和互动、简洁处理、正式稳妥三个候选。三者只允许改变语气和篇幅，不能改变事实、来源、待补充信息或安全限制。未命中 FAQ 的安全帖子也可提供三种通用候选，但必须标注“未命中 FAQ 规则”，且来源、待补充信息和 FAQ 版本保持为空；不得编造客服路径、活动事实或其他无来源承诺。高风险帖子不生成草案；草案仅本地维护，绝不发布到原平台。

更新资料时，先保留或替换 `sources/` 中经确认的原始工作簿，再审阅并修改 JSON 规则、递增 JSON 的 `version`、补充固定样本测试，最后重启 AI 审核 Worker。资料缺失或结构无效时，系统会跳过 FAQ 候选和草案生成，但不得中断原有 AI 审核、人工审核或处置流程。
