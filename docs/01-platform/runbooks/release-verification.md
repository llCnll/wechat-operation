# 发布环境验证清单

本清单记录自动化测试无法替代的受控环境核验。它是重复执行的发布门槛，不是当前通过状态；每次执行应在对应发布或验证记录中注明版本、系统环境、日期、执行人、结果和未执行原因。

自动化测试和模块行为场景分别以 CI 与 OpenSpec 主规格为准。本清单只覆盖需要受控浏览器、操作系统进程生命周期或长范围上游数据的检查。

## 受控会话页

- [ ] 在受控浏览器检查扫码页、稳定登录页、验证后导航回扫码页和 Frame 最小只读查询。
- [ ] 确认外层会话检查和人工观察使用同一受控页面，不创建额外 HOME。
- [ ] 检查中断、登录失效和 Frame 未就绪时的状态提示；不得记录 Cookie、token、完整认证 URL 或 target ID。

## Supervisor 与受控 Chrome

在 macOS、Windows、Linux 的受控环境分别核验：

- [ ] Supervisor lease 失效后，所属 Web/Worker 按受控流程停止，同一 Worker 职责不会重复并发启动。
- [ ] 正常关闭释放项目 Web 端口和受控 Chrome 端口；遗留 Chrome 先接收 Browser.close，只有固定 127.0.0.1:9222 仍被监听时才处理该端口的监听进程。
- [ ] Chrome 启动器 PID 变化但 browser generation 未变时不替换浏览器；generation 连续失败达到熔断条件后停止自动恢复。
- [ ] Windows 与 Linux 上验证租约立即撤销、已登记 Web/Worker 回收，以及 PID、创建时间、argv 或工作目录不符时跳过进程。
- [ ] 检查 Supervisor 诊断不泄露 PID、实例标识、target ID、URL、Cookie、token 或 capability。

## 高风险业务路径

- [ ] 人工写操作使用明确授权的受控测试账号，核验写前状态、单次提交、写后回读、重复确认幂等和失败诊断；禁止用真实用户做验证。禁言写入的复核间隔和操作边界按[运行与恢复手册](operations.md)执行。
- [ ] 验证 AI 自动处置在授权、规则、证据、阈值、状态或限额任一条件不满足时不写入；成功处置必须进入 AI 操作复审。
- [ ] 验证高风险帖子不生成回复草案；编辑、复制或本地采纳草案不产生原平台请求。

## 指标与报告

- [ ] 使用不少于 30 天的受控范围，核验五个日指标来源的开关、乱序、缺日不补零、checkpoint、登录延后和错误分类。
- [ ] 核验完整业务日与不完整日期的展示；周度核验全零占位不覆盖已验证快照、分阶段复核和待复核状态不会显示成真实零。

详细行为和边界以 config、jobs、reviews、reporting 与 service_supervisor 模块规格为准；重复运维步骤见[运行手册](operations.md)。本清单不定义新的运行行为。
