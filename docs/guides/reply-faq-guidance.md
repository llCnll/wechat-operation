# 回复 FAQ 资料维护

原始《城主别慌张》回复 FAQ 工作簿是运营口径原件，固定归档于 [`reviews/data/sources/《城主别慌张》游戏圈帖子回复FAQ参考.xlsx`](../../reviews/data/sources/%E3%80%8A%E5%9F%8E%E4%B8%BB%E5%88%AB%E6%85%8C%E5%BC%A0%E3%80%8B%E6%B8%B8%E6%88%8F%E5%9C%88%E5%B8%96%E5%AD%90%E5%9B%9E%E5%A4%8DFAQ%E5%8F%82%E8%80%83.xlsx)，用于审阅和追溯；服务运行时不直接读取 Excel。

运行时只读取 `reviews/data/city-lord-reply-faq.v1.json`。每条规则必须保留稳定 ID、场景、关键词、回复要点、待补充信息、原始来源定位和禁止承诺；变更后需更新资料版本、固定样本测试和 AI 审核 Worker。

FAQ 命中的安全帖子提供亲和互动、简洁处理、正式稳妥三个候选。三者只允许改变语气和篇幅，不能改变事实、来源、待补充信息或安全限制。未命中 FAQ 的安全帖子也可提供三种通用候选，但必须标注“未命中 FAQ 规则”，且来源、待补充信息和 FAQ 版本保持为空；不得编造客服路径、活动事实或其他无来源承诺。高风险帖子不生成草案；草案仅本地维护，绝不发布到原平台。

更新资料时，先保留或替换 `sources/` 中经确认的原始工作簿，再审阅并修改 JSON 规则、递增 JSON 的 `version`、补充固定样本测试，最后重启 AI 审核 Worker。资料缺失或结构无效时，系统会跳过 FAQ 候选和草案生成，但不得中断原有 AI 审核、人工审核或处置流程。
