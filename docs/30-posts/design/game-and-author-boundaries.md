# 游戏范围与作者状态边界

## 关键取舍

### 授权目录与当前操作范围分离

- 背景：平台账号可管理多个游戏，但当前服务按单一范围运行。
- 决策：同步只更新授权目录；切换当前游戏是另一项显式操作；无目录时不创建默认 AppID。
- 否决方案：迁移播种默认游戏、从帖子历史猜游戏，或同步成功即自动切换。
- 约束：页面过滤、来源 Job 和执行 scope 以当前已选游戏为界；已冻结任务不随切换改写。
- 重新评估：需要多游戏并行时，先验证跨游戏会话 lease、消费者并发和写操作审计隔离。

### 作者状态不附着于帖子生命周期

- 背景：作者可能出现在多篇帖子中，帖子也可能删除、隐藏或失去读取权限。
- 决策：禁言状态按作者身份和来源游戏维护；帖子只保存最小身份发现投影。
- 否决方案：把作者状态嵌入帖子或每次打开页面实时读取作者资料。
- 约束：只有已核验的作者身份允许进入作者治理；普通搜索和报表不暴露身份标识。
- 重新评估：若平台改变作者 ID 稳定性或授权语义，先调整身份契约和数据保留边界。
